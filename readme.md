# АИС «Продажа паллет»

Программный модуль для интернет-платформы по продаже паллет (поддонов).

## Назначение системы
Автоматизация ключевых бизнес-процессов торговой компании:
- ведение каталога паллет (типы, материалы, состояния);
- учёт клиентов (оптовых и розничных);
- оформление и отгрузка заказов;
- формирование чеков в формате PDF.

## Технологии
- Язык программирования: C#
- Интерфейс: WPF (.NET 6+)
- СУБД: Microsoft SQL Server
- Среда разработки: Microsoft Visual Studio 2022
